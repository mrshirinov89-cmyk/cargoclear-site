Поиск кода ТН ВЭД

Опишите товар своими словами или введите код — покажем подходящие коды ТН ВЭД ЕАЭС с пошлиной и НДС. Бесплатно и без регистрации.

Результат предварительный. Окончательный код подтверждает наш брокер по документам и составу товара.

Как работает поиск

  • По коду. Введите 4–10 цифр — покажем все коды этой группы с пошлиной и НДС.
  • По описанию. Напишите товар своими словами: из чего сделан, для чего, в каком виде. Искусственный интеллект выберет до трёх подходящих кодов — только из официального справочника, выдуманный код не пройдёт.
  • Ставки — из Единого таможенного тарифа ЕАЭС, справочник обновляется ежедневно. НДС 10 % — для товаров из перечня Постановления Правительства № 908, остальные — 22 %.

Почему код так важен

  • От кода зависят пошлина, НДС, нужные сертификаты, фитоконтроль и маркировка.
  • Неверный код — доначисление платежей, штраф и задержка груза на складе.
  • Для одного товара часто подходят несколько кодов: свежие и сушёные фрукты, детали и готовые изделия. Брокер выбирает по документам и составу.

Частые вопросы

Что такое код ТН ВЭД?

Десятизначный код товара по Товарной номенклатуре внешнеэкономической деятельности ЕАЭС. По нему определяют пошлину, НДС и требования к ввозу.

Можно ли доверять подбору кода на сайте?

Это предварительный подбор. Коды берутся из официального справочника, но окончательный код определяет брокер по документам, составу и назначению товара.

Какая ставка НДС при ввозе?

22 % для большинства товаров. 10 % — для продовольственных и детских товаров из перечня Постановления Правительства № 908, например свежих фруктов.
